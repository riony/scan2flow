# Working scope

This is a separate, local geometry-to-CFD scaffold built from copies. Never reorganize, clean, move or delete files in its upstream evidence archive. All development outputs belong in this repository or an explicitly chosen disposable workspace.

Capture videos, photographs, frame crops, mask overlays, credentials, reconstruction workspaces and model weights do not belong here. Preserve truthful fixture provenance in documentation. Excluding upstream inference from package scope does not change how the input geometry was produced.

The production implementation currently covers inspection only. Keep prototype migration bounded and explicit; do not silently turn a permissive prototype parser into an acceptance gate. Distinguish topology checks from physical fidelity, and units from assumed metric scale.

Local setup does not authorize publication, uploading or recorded external sessions. Licence and sharing status are in LICENSE_STATUS.md. Do not grant rights or assert contractual terms that have not been established.
